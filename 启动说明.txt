求职信息网站 - 启动说明
=====================================

方式一：使用启动脚本（推荐）
---------------------------
双击运行 start.bat 文件，会自动安装依赖并启动前后端服务。

方式二：手动启动
---------------------------
1. 打开两个命令行窗口

2. 第一个窗口（后端）：
   cd backend
   npm install
   npm start

3. 第二个窗口（前端）：
   cd frontend
   npm install
   npm run dev

4. 在浏览器中访问：http://localhost:3000

生成示例Excel文件（可选）
---------------------------
如果需要测试数据，可以运行：
python create_sample_excel.py

注意：需要先安装 openpyxl
pip install openpyxl

Excel文件格式要求
---------------------------
第一行必须是表头，包含以下列：
- 更新日期
- 公司
- 行业
- 标签
- 批次
- 职位
- 地点
- 投递截止
- 操作

如果遇到问题
---------------------------
1. 确保已安装 Node.js (版本 14 或更高)
2. 确保端口 3000 和 3001 未被占用
3. 检查防火墙设置
